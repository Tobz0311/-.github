# Support

If you need help with this project, you can:

- Check the project documentation.
- Search existing GitHub issues.
- Open a new issue using the appropriate issue template.

## Reporting Problems

If you encounter a bug, use the Bug Report template and include steps to reproduce the problem.

## Requesting Features

If you have an idea for an improvement, use the Feature Request template.
