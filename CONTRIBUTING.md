# Contributing Guidelines

Thank you for considering contributing to this project!

## How to Contribute

1. Check existing issues before reporting a problem.
2. Create an issue to discuss proposed changes.
3. Create a separate branch for your work.
4. Make your changes and test them.
5. Submit a pull request describing your changes.

## Code Guidelines

- Write clear, readable code.
- Follow the existing coding style.
- Include comments where necessary.
- Test changes before submitting them.

## Reporting Bugs

Use the repository's bug report issue template and provide clear steps to reproduce the problem.

## Suggesting Features

Use the feature request issue template to describe your suggestion.

Thank you for helping improve the project!
