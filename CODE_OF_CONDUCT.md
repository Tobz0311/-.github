# Code of Conduct

## Our Standards

All contributors are expected to:

- Be respectful and welcoming.
- Be considerate of different opinions.
- Accept constructive feedback.
- Focus on what is best for the project.
- Treat everyone fairly.

## Unacceptable Behaviour

- Harassment or discrimination.
- Insulting or offensive comments.
- Personal attacks.
- Unwelcome behaviour towards other contributors.

## Responsibilities

Project maintainers are responsible for clarifying and enforcing these standards.

## Scope

This Code of Conduct applies to all project spaces, including issues, pull requests and discussions.

Thank you for helping maintain a positive community.
