# Accessibility

## Our Commitment

We aim to make this project accessible and usable by everyone.

## Accessibility Guidelines

- Use clear and understandable language.
- Provide meaningful labels for interface elements.
- Ensure sufficient colour contrast.
- Support keyboard navigation where possible.
- Consider users with different accessibility needs.

## Reporting Accessibility Issues

If you encounter an accessibility problem, please report it through GitHub Issues using the General Issue template.

We welcome suggestions for improving accessibility.
